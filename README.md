# California Housing Streamlit Dashboard

An interactive data visualization dashboard built with Streamlit using the California Housing dataset.

This project allows users to explore housing price distributions, income levels, and geographical patterns through dynamic filters and visualizations.

---

## Features

- Interactive house price filtering
- Income level filtering
- Ocean proximity filtering
- Geographic map visualization
- House value distribution histogram
- Dynamic data table display

---

## Dataset

The dataset contains California housing information including:

- Median house value
- Median income
- Ocean proximity
- Population
- Latitude & longitude

Total records: 20,640+

---

## Technologies Used

- Python
- Streamlit
- pandas
- matplotlib

---

## How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit app:

```bash
streamlit run app.py
```
